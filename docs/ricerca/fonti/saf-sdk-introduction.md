## Introduction

This chapter contains documentation for the software development kit available to [download at nuget.org](https://www.nuget.org/profiles/StructuralAnalysisFormat). SDK is written in C#.NET and it aims to help with the implementation of SAF format into any software.

> [!tip] Tip
> Check all the dependencies at [nuget.org](https://www.nuget.org/profiles/StructuralAnalysisFormat) under the dependencies tab for each package.

There are 4 packages available:

- The main package - **[StructuralAnalysisFormat](https://www.saf.guide/en/stable/SDK/StructuralAnalysisFormat.html)** contains import/export functionality from and to the Structural Analysis Format in Excel.
- **[StructuralAnalysisBootstrappers.SimpleInjector4](https://www.saf.guide/en/stable/SDK/StructuralAnalysisFormat.Bootstrappers.SimpleInjector4.html)** package contains functionality to bootstrap SAF using SimpleInjector 4.
- **[StructuralAnalysisBootstrappers.SimpleInjector5](https://www.saf.guide/en/stable/SDK/StructuralAnalysisFormat.Bootstrappers.SimpleInjector5.html)** package contains functionality to bootstrap SAF using SimpleInjector 5.
- **[StructuralAnalysisFormat.Tests.Infrastructure](https://www.saf.guide/en/stable/SDK/StructuralAnalysisFormat.Tests.Infrastructure.html)** package contains objects and feature useful when creating tests.
