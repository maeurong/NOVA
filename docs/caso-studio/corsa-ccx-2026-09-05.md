## Cosa manca

- Spostamenti in sommità (`TOP`): stanno nel `.frd` (`NODE FILE U`), non nel `.dat`; si leggono in
  T3 con `meshrec.core.solve.leggi_frd` riusato. Il tentativo di lettura a mano con `awk` sul
  formato a colonne fisse non è affidabile e non è riportato.
- Nessuna prova di carico documentata: ogni confronto resta verifica del codice.

## Comandi

```bash
cp lab_telaio_v2/wall_model.inp <tmp>/ && cd <tmp>
OMP_NUM_THREADS=6 /usr/bin/time -p ccx -i wall_model > ccx_stdout.log 2>&1
# Σ reazioni per passo, blocco «forces (fx,fy,fz) for set BASE», fino a «S T E P 4»
LC_ALL=C awk '...' wall_model.dat
```
